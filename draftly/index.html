What this repo can become

This first pass is a product shell. The next layers are straightforward: auth, workspace sync, action execution, LLM orchestration, and a durable command log.

Phase 1

  • OAuth and workspace sync
  • Item view, labels, and reminders

  • Context integrations and action execution
  • Audit trail for assistant actions

Phase 3

  • Multi-channel assistant interface
  • User-defined automations and agent recipes
  • Self-hosted deployment templates
